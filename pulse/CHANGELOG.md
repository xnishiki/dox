# Список изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Новые пункты пишутся в раздел «Unreleased»; команда `npm run release` переносит их в раздел новой версии.

## [Unreleased]

### Добавлено
- Автоматическое онлайн-обновление: Pulse сам проверяет новые версии, скачивает их в фоне и ставит по одной кнопке.
- Каналы обновлений «Стабильный» и «Бета».
- Раздел «Обновления» в настройках и страница «Что нового».
- После обновления музыка продолжает играть с того же места.

## [0.1.0] - 2026-11-24

### Добавлено
- Первая версия Pulse: главная, категории, поиск, «Поток», эквалайзер, плейлисты, аккаунты, локальные файлы.
